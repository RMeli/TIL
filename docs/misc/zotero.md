# Zotero

[Zotero](https://www.zotero.org/) is a free, easy-to-use tool to help you collect, organize, annotate, cite, and share research.

## Syncing

Zotero can sync files and data using the [WebDAV](https://www.zotero.org/support/sync#webdav) protocol.

ETHZ's polybox service supports WebDAV and can therefore be used to sync Zotero across devices.

The polybox WebDAV address is the following:
```
https://polybox.ethz.ch/remote.php/dav/files/USERNAME
```
where `USERNAME` is the ETHZ username.
